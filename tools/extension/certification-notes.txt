For students signed in to UConn's HuskyCT (https://lms.uconn.edu), which requires a NetID. We cannot provide a test account.

The helper reads HuskyCT endpoints with the browser's existing session: courses, announcements, deadlines, grades and file links. Results stay in this browser, reaching https://betterhuskyct.vercel.app locally. It never reads or saves passwords or cookies. No analytics or remote code.

Helper 2.2.0: background checks start ON for new installations, first after about one minute, then about every six hours while the browser runs. Existing saved off settings stay off; the popup can disable checks. Notifications start OFF and request permission only when enabled. No new permissions since 2.1.0. Alarms/offscreen run the packaged API reader without HuskyCT tabs. Only metadata is read; file contents need manual sync. An expired session pauses checks. Snapshots and up to 500 changes / 30 days wait in trusted local storage until the app saves and acknowledges them. Notification previews may show course names and titles.

Without an account, reviewers can:
1. Open the toolbar popup on a new install: checks on, notifications off. Run now while signed out reports sign-in required without opening HuskyCT. A saved off choice survives restart/update.
2. Open https://betterhuskyct.vercel.app/. Check for updates uses the background reader. Materials retains manual file sync. The former /helper URL redirects home.
3. Inspect all bundled source at https://github.com/NoGod3524/betterhuskyct (tools/extension and tools/huskyct-helper). Privacy: https://betterhuskyct.vercel.app/privacy.
