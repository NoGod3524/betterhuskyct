This extension works only for students signed in to UConn's HuskyCT (https://lms.uconn.edu), which needs a UConn NetID. We cannot provide a test account, so the data-reading part cannot be exercised by a reviewer without one.

What it does: after the student signs in, the helper asks HuskyCT's own web endpoints (same origin, using the browser's existing session) for the student's courses, announcements, due dates, grades and course file links, and hands the result to the BetterHuskyCT dashboard (https://betterhuskyct.vercel.app) inside the browser. It never reads or stores a NetID, password or cookie, makes no request to any host other than lms.uconn.edu, and has no analytics. No remote code: everything is in the package. The permissions are the same as in the version before.

What a reviewer can check without an account:
1. Open https://betterhuskyct.vercel.app/helper. The extension injects a small bridge there; the page's Sync button then asks the extension to open HuskyCT in a background tab.
2. Open https://lms.uconn.edu while signed out. The helper detects the sign-in page and reports that the student is signed out; it reads nothing.
3. Read the source, which is exactly what is in the package: https://github.com/NoGod3524/betterhuskyct (tools/extension and tools/huskyct-helper). The privacy policy is at https://betterhuskyct.vercel.app/privacy.
